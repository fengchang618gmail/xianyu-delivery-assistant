## 1. 准备清单

在开始之前，请确认以下条件：

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 10 / 11，64 位 | 仅支持 Windows，macOS / Linux 不可用 |
| 浏览器 | Chrome 或 Edge（较新版本） | 扩展只能手动加载，无法静默安装 |
| 网络 | 可访问闲鱼、飞书 | 安装时若缺少 WebView2 组件还需联网下载 |
| 飞书 | 有权限创建「企业自建应用」 | 需要飞书管理员或开发者权限 |
| 飞书多维表格 | 一张商品表 | 必须包含 `商品 ID`、`商品标题`、`发货内容` 三列 |
| 闲鱼 | 已登录的卖家账号 | 登录态保留在你自己的浏览器里，本应用不保存 |

### 关于 WebView2（重要依赖）

本应用界面基于 Microsoft Edge WebView2 运行：

- **Windows 11** 和**较新的 Windows 10** 已内置 WebView2，安装包会直接跳过这一步。
- 如果系统里没有，安装程序会**自动联网下载并安装** WebView2 Runtime，此时需要保持网络畅通。
- 若你的电脑无法访问微软服务器，可先手动安装官方运行时（搜索「Microsoft Edge WebView2 Runtime 下载」），再运行本安装包。

### 关于安装包内的浏览器扩展

浏览器扩展**已经打包在安装包里**，不需要你另外下载。安装完成后，向导会告诉你扩展所在目录，你在浏览器里手动加载一次即可（见第 3 章第 ① 步）。

## 2. 安装应用

1. 找到安装包 `闲鱼发货助手_0.1.0_x64-setup.exe`，**双击运行**。

2. 如果 Windows 弹出蓝色的「Windows 已保护你的电脑」提示（SmartScreen）：

   - 点击 **更多信息** → **仍要运行**。
   - 这是因为安装包没有购买商业代码签名证书，属于正常现象。介意的话，可以先用第 6 章的校验值核对安装包完整性。

3. 按安装向导点击下一步完成安装。

   - 安装模式为「**仅当前用户**」，**不需要管理员权限**，也不会改动系统级目录。
   - 安装完成后，开始菜单和桌面会生成「闲鱼发货助手」快捷方式。

4. 首次启动后，你会看到「闲鱼发货助手 · 首次配置」的 6 步向导。**不要关掉它**，按下一章逐步操作。

> **小提示**：应用可以在后续任何时候从开始菜单 / 桌面快捷方式启动，不需要重新安装。向导只在配置未完成时出现。

## 3. 首次配置：6 步向导

向导的 6 步是：**① 浏览器连接 → ② 闲鱼登录 → ③ 飞书应用 → ④ 飞书授权 → ⑤ 商品库校验 → ⑥ 安全测试**。
每一步失败都可以返回上一步重来；**缺少任何一步的配置，任务都不会真正发送**（这是刻意的安全设计）。

### ① 安装浏览器连接组件

这一步把「桌面应用」和「浏览器扩展」连起来。

1. 点击 **「注册本机组件」**。
   这一步会向注册表写入 Chrome / Edge 的 Native Messaging 宿主配置，让扩展能和应用通信。
   写入位置：`HKEY_CURRENT_USER\Software\Google\Chrome\NativeMessagingHosts\...` 与对应的 Edge 项。

2. 点击 **「打开 Chrome 扩展页」** 或 **「打开 Edge 扩展页」**，浏览器会打开扩展管理页。

3. 在扩展页右上角打开 **「开发者模式」**。

4. 点击 **「加载已解压的扩展程序」**，然后选择界面上显示的 **扩展目录**（在向导里有一行「扩展目录：……」的等宽文字，直接复制或按提示定位）。

   - 该目录通常位于应用安装目录下的 `extension` 文件夹。
   - 扩展 ID 已固定为 `lkfdpfllnpejncdiggdbiffiebombajd`，无需手动修改任何文件。

5. 回到应用，确认状态灯变为 **● 扩展已连接**，然后点「下一步」。

> **指示灯不变绿怎么办？**
> 浏览器会让扩展后台休眠。请在浏览器里**点击一次扩展图标**，或者**刷新一次闲鱼卖家页面**，扩展就会自动重连。之后点应用里的「重新检查」即可。

### ② 登录闲鱼卖家工作台

1. 点击 **「打开闲鱼卖家页」**，在**装有扩展的那个浏览器**里打开 `https://seller.goofish.com/`。
2. 完成登录，确认能看到**聊天**和**订单**页面。
3. 回到应用，点「我已登录，下一步」。

> 登录态完全留在你自己的浏览器中，本应用**不保存**闲鱼账号、密码、Cookie，也不保存浏览器配置。

### ③ 填写飞书应用凭据

这一步需要你在飞书开放平台准备一个「企业自建应用」。

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，**创建企业自建应用**。

2. 进入 **「权限管理」**，开通以下三项权限：

   | 权限 | 用途 |
   | --- | --- |
   | `bitable:app:readonly`（查看、评论、导出多维表格） | 只读读取你的商品库 |
   | `wiki:node:read`（获取知识空间节点信息） | 当多维表格放在知识库里时解析分享链接 |
   | `offline_access`（离线访问） | 让令牌自动续期，避免每次都重新授权 |

3. **创建版本并发布**。权限变更后必须发布新版本才会生效（如果是需要管理员审批的权限，记得让管理员通过）。

4. 在应用的「凭证与基础信息」页复制 **App ID** 和 **App Secret**。

5. 回到本应用，把 **App ID** 和 **App Secret** 填入对应输入框，点「保存并下一步」。

> App Secret 只会存进 **Windows 凭据管理器**，不会以明文写进任何文件。

### ④ 飞书授权

1. **先做一件事**：在飞书开发者后台，进入你应用的 **「安全设置」→「重定向 URL」**，添加下面这条地址并保存：

   ```
   http://127.0.0.1:15731/callback
   ```

   不添加的话，飞书会报「重定向 URL 有误」。

2. 回到应用，点击 **「开始授权」**，浏览器会打开飞书登录页，同意授权。

3. 授权成功后，应用里会显示 **● 已授权**，令牌已安全保存，后续会自动续期。

> 授权范围是**只读**（读取你选择的多维表格），本应用不会修改你的表格。

### ⑤ 校验商品库

1. 在飞书里打开你的**商品多维表格**，点「分享」，复制链接（`/base/` 直链或知识库 `/wiki/` 链接都可以）。

2. 把链接粘贴到应用里的「多维表格链接」输入框，点 **「读取数据表」**。

3. 如果文档里有多个数据表，下拉选择正确的那一张，再点 **「校验字段」**。

4. 校验通过的条件：

   - 表里存在三列：**`商品 ID`**、**`商品标题`**、**`发货内容`**；
   - 商品 ID 无重复；
   - 发货内容不为空。

   校验通过后，可以展开「查看脱敏样例」看一眼真实模板长什么样（链接、提取码等会被自动打码）。

5. 点「下一步」。

> **匹配规则**（了解它有助于你理解为什么某些订单没有自动发货）：
> 先用**商品 ID 精确匹配**；只有在网页上提取不到商品 ID 时，才用**标准化后的商品标题**精确匹配兜底。
> **零条匹配或多条匹配都不会发送**，宁可停下等人处理。

### ⑥ 安全测试预览

这一步只展示一条脱敏后的真实模板样例，**不会向任何买家发送任何内容**。
确认无误后点 **「完成，进入工作台」**，配置就结束了。

## 4. 日常使用

进入工作台后，你会看到：连接状态、发送模式、待确认任务、最近任务、安全日志（脱敏）。

### 4.1 发送模式

| 模式 | 行为 |
| --- | --- |
| **确认后发送**（默认） | 订单出现后进入「待确认」列表，你核对内容并点「确认发送」才会发出。 |
| **自动发送** | 校验通过后自动填入并发送；遇到任何不确定情况（订单状态变化、商品不一致等）会**降级为人工确认**，不会盲目发送。 |

自动模式的安全机制：发现订单后会有一次 **60 秒二次校验**，只有订单仍处于「等待卖家发货」且商品完全一致时才批准发送。

### 4.2 主要操作

- **暂停 / 恢复**：暂停后所有新订单都会被忽略，适合你临时离开或不想处理时使用。
- **待确认任务卡片**：可以**直接编辑内容**再发送；发送前请再核对一遍。
- **最近任务**：查看历史任务及其状态（已完成 / 异常 / 已取消 / 已忽略）。
- **安全日志（脱敏）**：所有动作都有记录，链接、提取码、邮箱、长数字会被替换成占位符。
- **清除全部记录**：一键擦除本地数据库与凭据。
- **断开飞书授权**：单独撤销飞书的令牌。

### 4.3 关于数据存放位置

| 内容 | 位置 |
| --- | --- |
| 本地数据库（任务、缓存、审计） | `%APPDATA%\com.local.xianyu.deliveryassistant\data.db` |
| 飞书令牌（DPAPI 加密） | `%APPDATA%\com.local.xianyu.deliveryassistant\feishu_tokens.bin` |
| 飞书 App Secret | Windows 凭据管理器 |
| 本机通信令牌 | `%APPDATA%\com.local.xianyu.deliveryassistant\nm_token` |

发货内容的明文只在任务进行期间短暂存在；任务终结后会清空明文，只保留加盐哈希摘要。

## 5. 常见问题排查

### 安装相关

**Q：双击安装包没反应 / 被 SmartScreen 拦截。**
点「更多信息」→「仍要运行」。安装包未做商业代码签名，属正常提示。

**Q：安装时报「Error opening file for writing ... nmhost.exe」。**
这是浏览器扩展在后台反复拉起通信组件导致的文件占用。安装包已内置处理逻辑（先结束进程再写入），如果仍然出现：**先完全退出 Chrome / Edge**（任务管理器里确认没有残留进程），再重新运行安装包。

**Q：安装后应用打不开 / 界面白屏。**
通常是缺少 WebView2 运行时。联网后重新运行安装包，或手动安装 Microsoft Edge WebView2 Runtime 后重试。

### 浏览器连接相关

**Q：向导第 ① 步指示灯一直是「尚未检测到扩展连接」。**
按顺序检查：

1. 扩展是否真的加载了（浏览器扩展页里能看到「闲鱼发货助手」且已启用）；
2. 是否点了「注册本机组件」（状态行显示「宿主已注册：是」）；
3. 在浏览器里**点击一次扩展图标**或**刷新闲鱼卖家页面**唤醒它（后台休眠是浏览器的正常行为）；
4. 点应用里的「重新检查」。

**Q：重启电脑 / 重启应用后扩展又连不上了。**
同上，点一下扩展图标或刷新闲鱼页面即可。扩展每 30 秒会尝试重连。

**Q：装完应用后，扩展在浏览器里被自动禁用了。**
重新在扩展页启用一次即可。手动加载的扩展在浏览器重启后有时需要重新确认。

### 飞书相关

**Q：提示「重定向 URL 有误」。**
在飞书开发者后台「安全设置 → 重定向 URL」添加 `http://127.0.0.1:15731/callback` 并保存。

**Q：提示权限未开通 / 授权时少了某项权限。**
回到向导第 ③ 步核对三项权限（`bitable:app:readonly`、`wiki:node:read`、`offline_access`），**发布新版本**后重新授权。

**Q：同步商品库失败，提示「令牌请求失败：error sending request for url (…/authen/v2/oauth/token)」。**
这是网络传输层抖动（飞书 CDN 到本机偶发不稳）。应用已对令牌请求做自动重试；若仍失败，稍等片刻再点一次「同步」。若反复失败，日志里会给出更具体的错误类别，可据此排查本地网络或代理。

**Q：读取表格报 `1254045 FieldNameNotFound`。**
你的列名和标准名有细微差异（例如「商品ID」少了一个空格）。应用已做容错匹配，但仍建议把列名改成完全一致的 **`商品 ID` / `商品标题` / `发货内容`**。报错信息里会列出该表实际拥有的字段名，可对照检查。

**Q：多维表格在知识库里，链接是 `/wiki/…` 形式，读取失败。**
需要应用已开通 `wiki:node:read` 权限并发布版本，然后**重新授权**一次（新增权限需要重新授权才会进入令牌）。

**Q：授权后过一段时间又要重新授权。**
令牌续期依赖 `offline_access` 权限。请确认应用已开通该权限并发布，且授权链接已包含该范围。

### 发货相关

**Q：订单出现了但没有自动发送。**
先看它是不是停在「待确认」——自动模式遇到任何不确定情况都会降级为人工确认。常见原因：

- 商品 ID / 标题在表格里**匹配到 0 条或多条**；
- 表格里该商品的**发货内容为空**；
- 订单在二次校验时**状态已变化**。

**Q：内容提取不到商品 ID / 标题。**
本版本的选择器是基于常见页面结构编写的，**尚未在真实闲鱼页面完整实测**（见第 7 章诚实清单）。如果识别异常，欢迎在 GitHub 提 Issue 并附上页面结构（请务必打码买家信息）。

**Q：提示发送失败。**
应用不会盲目重发。请到闲鱼聊天窗口确认实际状态，再在应用里手动处理该任务。

## 6. 卸载与数据清理

### 只清理数据（保留应用）

在工作台点击 **「清除全部记录」**，会擦除本地数据库与飞书凭据；也可单独点「断开飞书授权」。

### 完全卸载

1. **设置 → 应用 → 已安装的应用**，找到「闲鱼发货助手」，点卸载。
   （或运行安装目录下的卸载程序。）
2. 卸载程序会先结束通信组件进程，并清理 Native Messaging 注册。
3. 如需彻底清除残留，手动删除：
   - 目录 `%APPDATA%\com.local.xianyu.deliveryassistant`
   - Windows 凭据管理器中的飞书凭据条目
   - 注册表 `HKEY_CURRENT_USER\Software\Google\Chrome\NativeMessagingHosts` 与 `HKEY_CURRENT_USER\Software\Microsoft\Edge\NativeMessagingHosts` 下的 `com.local.xianyu.deliveryassistant` 项
4. 在浏览器扩展页把「闲鱼发货助手」扩展移除。
