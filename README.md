# 闲鱼发货助手

> 用你自己的浏览器，把飞书多维表格里的发货内容，在买家下单后自动（或确认后）发给买家。

一个 **Windows 桌面应用 + 浏览器扩展** 的组合工具：监控闲鱼卖家后台里「等待卖家发货」的订单，
按**商品 ID 精准匹配**飞书多维表格中的发货内容，再通过**你自己已登录的浏览器聊天窗口**把内容发出去。

- 默认**「确认后发送」**，每一步都可人工干预；自动模式遇到任何不确定情况一律降级为人工确认。
- 不调用任何大模型 API，不抓取私有接口，不伪造请求，不绕过验证。
- 所有动作都有**脱敏审计日志**：链接、提取码、邮箱、长数字都会被替换成占位符。

## 它能做什么

1. 你在飞书多维表格里维护一张商品表，包含三列：**`商品 ID`**、**`商品标题`**、**`发货内容`**。
2. 买家下单后，订单进入「等待卖家发货」，浏览器扩展识别到该订单。
3. 桌面应用按商品 ID（精确匹配优先，标准化标题兜底）到飞书表格取发货内容。
4. 由扩展把内容填入你自己的闲鱼聊天窗口并发送。

**不会做的事**：不保存你的闲鱼密码 / Cookie / 浏览器配置；不调用大模型；不抓私有接口；
零条或多条匹配、内容为空时**一律不发送**。

## 安全与隐私边界（务必阅读）

- 闲鱼登录态**完全留在你自己的浏览器里**，本应用不保存闲鱼账号、密码、Cookie。
- 飞书 App Secret / Token 存在 **Windows 凭据管理器**；令牌文件使用 DPAPI（当前用户）加密，不落明文。
- 发货内容只在任务进行期间短暂存在于内存 / 数据库；任务终结时清空明文，仅保留**加盐 sha256 摘要**。
- 审计日志全部脱敏（链接、提取码、邮箱、长数字 → 占位符）。
- 发送动作需要**一次性批准令牌**，超时不盲目重发；自动模式在订单状态或商品不一致时降级为人工确认。
- 「清除全部记录」可一键擦除本地数据库与凭据。

## 已知限制（诚实清单）

- 扩展的 DOM 选择器（商品 ID / 标题提取、输入框与发送按钮定位）**尚未在真实闲鱼页面完整实测**。
  代码采用多重防御性选择器 + DOM 健康检查，但首次使用可能需要按你的实际页面结构微调 `extension/content.js`。
- 飞书端到端流程需要你完成授权后才能真实验证；建议**先在测试商品上跑通**再用于真实订单。
- 浏览器扩展**无法静默安装**，必须在浏览器扩展页手动「加载已解压的扩展程序」一次。
- 本工具通过你自己的浏览器和账号操作闲鱼页面，**请自行确认是否符合平台用户协议**，账号风险由使用者承担。
- 仅支持 Windows 10 / 11 64 位。

## 开发

环境要求：Windows 10/11 + Node 18+ + Rust (MSVC) + Visual Studio Build Tools（含 Windows SDK）。

```bash
npm install                  # 前端依赖
npm run check                # TypeScript 类型检查
cd src-tauri && cargo test   # Rust 测试（16 个用例）
npm run package:windows      # 生成 NSIS 安装包
```

调试：`npx tauri dev`。注意 `tauri.conf.json` 的 `externalBin` 要求
`src-tauri/binaries/nmhost-x86_64-pc-windows-msvc.exe` 在编译期就存在：
先跑一次 `scripts\package-windows.cmd` 生成真实产物，或先创建占位文件解锁编译，再由打包脚本覆盖。

> 8 GB 内存的机器请注意：`src-tauri/.cargo/config.toml` 已限制 `jobs = 4` 且禁用了 fat LTO，
> **编译时请勿与其他重负载并行**。仓库内 `scripts/safe-build.ps1` 是带内存看门狗的构建脚本。
